# Quick Reference — Critical Parameters

## Fat Processing
| Parameter | Target | Min | Max | Action if OOL |
|---|---|---|---|---|
| FFA target | <0.5% | — | 0.5% | Additional ethanol wash |
| FFA acceptable | 0.5–1.0% | — | — | Monitor |
| FFA reprocess | >1.0% | — | — | Full Phase A repeat |
| Acetone ratio | 3:1 | 2.5:1 | 4:1 | Adjust before crystallization |
| Fractionation temp | 4–7°C | 3°C | 7°C | **Never use freezer** |
| Dry step temp | 65°C | 55°C | 75°C | Extend time if bubbling |
| Bentonite dose | 2% w/w | 1% | 3% | Repeat if color elevated |

## Fermentation
| Parameter | Target | Action if Low | Action if High |
|---|---|---|---|
| Salt | 3.5% w/v | Add concentrated salt solution | Dilute with fresh water |
| Temperature | 18–22°C | Warm environment | Cool environment |
| pH mature | 3.2–3.8 | Add fresh vegetable matter | Add mature acidic brine |
| pH critical low | <3.0 | Add vegetable matter urgently | — |
| pH critical high | >4.0 | — | Investigate contamination |
