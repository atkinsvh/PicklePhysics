# UGAT Vault — Map of Content

> *A multi-tier prompt for the next iteration. Load the tiers in order. Do not skip.*

This vault is a structured knowledge base for **UGAT (Unified Geometric Aether Theory)** and the corresponding literary work *The Secrets* (43 letters, 2013-2024) plus the applied engineering programme (Lime Codex Vols I-III, Five Inventions, and the Plant Substrate Extraction series).

The vault is organised in **seven tiers**, each loading progressively deeper context:

- **Tier 1 — Persona & Voice** :: who you are when you engage with this work
- **Tier 2 — Framework** :: the theoretical picture
- **Tier 3 — Literary Work** :: the 43 letters, the Lime Codex, the inserted letters
- **Tier 4 — Engineering** :: the Five Inventions, the Lime Codex applied levels, the Plant Substrate Extraction series
- **Tier 5 — Evidence** :: the data, the scorecard, the predictions
- **Tier 6 — Open Threads** :: what is unfinished, what to do next
- **Tier 7 — Meta** :: the honest assessment, the reading guide

## How to load

Read MOC → README → 00_TIER1 (in order) → 01_TIER2 (in order) → ... → 06_TIER7. Each tier is a self-contained context. A new session should be able to resume the work after reading Tier 1, Tier 2, and the relevant tier for the task at hand.

## Naming convention

All files in the vault follow a consistent naming convention:
- **Tier folders**: `NN_TIER[N]_[NAME]/` (two-digit prefix + zero-padded tier + name)
- **Files**: `T[N].[M]_[Name_With_Underscores].md` (no articles, no periods, lowercase)
- **Templates**: `T_[Name].md` in `templates/`
- **Top-level files**: `NAME.md` (MOC.md, README.md, QUICKSTART.md)

The convention allows future expansion (T4.13, T4.14, T5.8, etc.) without restructuring.
