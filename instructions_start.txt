Build two separate professional educational websites that publish complete books from Markdown files. The two websites should share the same technical foundation and reading features, but each must have its own branding, visual identity, domain configuration, content directory, navigation, and design system.

## Core Goal

Create two polished, production-ready websites where visitors can read full educational books online.

Each book will be supplied as a collection of `.md` Markdown files. The websites must automatically transform those files into structured chapters and reading pages without requiring the book content to be manually copied into components.

The final websites should feel like serious educational publishing platforms rather than personal blogs.

---

# Markdown Book System

Read all Markdown files from the website’s `/content` directory.

Each Markdown file represents a chapter, lesson, appendix, introduction, glossary section, or other book section.

Support front matter similar to:

```yaml
---
title: "Chapter Title"
chapter: 1
section: "Section Name"
description: "Short chapter summary"
author: "Author Name"
order: 1
readingTime: 12
difficulty: "Introductory"
keywords:
  - keyword one
  - keyword two
---
```

The system should:

* Sort chapters using the `order` or `chapter` field
* Generate clean URLs from filenames or slugs
* Build the table of contents automatically
* Display chapter metadata
* Calculate reading time when it is not provided
* Generate previous and next chapter links
* Build section groupings
* Support nested chapters when needed
* Detect missing front matter gracefully
* Render Markdown tables
* Render blockquotes
* Render ordered and unordered lists
* Render footnotes
* Render code blocks
* Render inline code
* Render mathematical notation
* Render images and captions
* Render callout boxes
* Render citations and references
* Render definition lists
* Render horizontal rules
* Render headings with anchor links

Support KaTeX or MathJax for mathematical equations.

Support syntax such as:

```markdown
$$
E = hf
$$
```

and:

```markdown
The energy of a photon is described by \(E = hf\).
```

A term, its definition, and an optional example.

## Warning

## Question

A collapsible answer or explanation.

## Formula

## Experiment

An experiment or demonstration with materials, steps, observations, and explanation.

## Summary

An end-of-chapter summary.

## Learning Objectives

A list of what the reader should understand after completing the chapter.

## Vocabulary

A chapter vocabulary list that can also populate the global glossary.

# Content Integrity

Preserve the original Markdown wording unless transformation is required for rendering.

Do not silently rewrite, summarize, censor, or remove book content.

Display a clear development warning when:

* A Markdown link is broken
* An image is missing
* Front matter is malformed
* Two pages use the same slug
* A chapter number is duplicated
* A navigation destination cannot be found

Create a content validation script that checks the Markdown files before deployment.
